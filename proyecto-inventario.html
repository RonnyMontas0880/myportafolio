Sistema de Inventario y Ventas

Proyecto académico desarrollado con SQL Server

Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema de inventario y ventas utilizando SQL Server. Fue creado como parte de mi formación en Ingeniería de Software y tiene como objetivo gestionar información relacionada con productos, categorías, proveedores, clientes y ventas.

Funcionalidades

  • Gestión de productos y categorías.
  • Registro de proveedores y clientes.
  • Registro y control de ventas.
  • Consultas utilizando JOIN y GROUP BY.
  • Procedimientos almacenados.
  • Vistas para consultar información.
  • Triggers para auditoría.
  • Transacciones y validaciones.
  • Roles y permisos de seguridad.
  • Optimización mediante índices.

Tecnologías utilizadas

SQL SQL Server JOIN Procedimientos almacenados Triggers Vistas Transacciones Seguridad

Sobre el proyecto

Este proyecto forma parte de mi experiencia académica y práctica trabajando con bases de datos. Me permitió aplicar conocimientos de SQL Server y comprender mejor cómo estructurar y administrar la información de un sistema.

Por motivos de seguridad y protección del proyecto académico, el código fuente completo no se encuentra publicado.
